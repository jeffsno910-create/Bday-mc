PRITI'S BIRTHDAY WEBSITE — LEGENDARY ADVENTURE EDITION
=====================================================

START HERE
----------
1. Extract the ZIP folder.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in a modern browser, or use VS Code Live Server.
4. Add the real photos, videos and birthday soundtrack using the exact names in the asset README files.

WHAT'S INCLUDED
---------------
- India Standard Time countdown to November 26.
- Animated gift → whistle → fireworks opening sequence and floating balloon garden.
- Photo memories, three video moments, birthday letter, wishes, cake ceremony, drawing studio,
  personal-letter area, selfie booth, final message and the existing secret-star surprise.
- Chapter-specific ambient backgrounds using the included high-resolution celestial artwork.
- Catch the Starlight: a replayable 60-second game with bonus hearts, cloud penalties, streak
  bonuses, pause/resume, a local best score and rotating sky artwork.
- Four Minecraft-inspired relics hidden in Memories, Videos, Birthday Letter and Art Studio.
  Collect Diamond, Golden Apple, Ender Pearl and Cake to unlock the birthday realm.
- NEW ADVENTURE: meet Pixel, a friendly blocky dog; activate the magic portal; discover the separate twelve-frame End Portal; travel to the End;
  awaken five star crystals; dissolve the Ender Dragon's shield with birthday starlight; and arrive
  in the Sweet Cherry Grove for a sky-shot fireworks show and a legendary birthday cake.
- BONUS CHAPTER: Pixel's Side-Quest Arcade, unlocked from the Cherry Grove after the main adventure.
  Play the harmless TNT confetti-vault rune puzzle, find three hidden Endermen, solve a 3×3 sliding
  jigsaw featuring Pixel, and finish the five-question yes/no birthday quiz. The refreshed arcade has a colourful
  Cherry Grove hero illustration, four vibrant game-cover scenes, large touch controls and a live 0/4 quest tracker.
- MOBILE FINISH: the main-page entrance no longer leaves a transform around fixed controls. On phones,
  the music player becomes a compact expandable dock; the tracker, back-to-top button and temporary
  toasts tuck away while the final birthday message is visible.
- SECRET: type CREEPER, or tap the small “for priti” logo five times quickly, to find a tiny cameo.

THE ADVENTURE FLOW
------------------
1. Find all four relics in the main site. The quest tracker shows your progress.
2. Open the portal and give Pixel a pat. The dog becomes your companion.
3. Activate the purple portal to reach an ancient stronghold.
4. Discover the separate 12-frame End Portal chamber and jump through its glowing surface.
5. Tap all five floating crystals. When the progress reaches 5/5, send birthday starlight to
   complete the friendly, non-graphic dragon challenge.
6. In the Sweet Cherry Grove, launch the sky-shot fireworks. Rockets visibly travel upward,
   burst into large layered displays, and finish with a multi-rocket finale. Reveal the cake too.
7. Open Pixel's Side-Quest Arcade for four optional mini-games: the harmless TNT rune sequence,
   Enderman hide-and-seek, a solvable 3×3 sliding picture puzzle, and a replayable yes/no quiz.

COUNTDOWN
---------
The countdown uses Asia/Kolkata time and targets midnight at the start of November 26. It rolls
forward to the next November 26 after the birthday.

PERSONAL MEDIA
--------------
The supplied files did not include Priti's photographs, videos or chosen music. The assets
folders contain exact filename instructions and the site shows graceful placeholders until
those personal files are added. Add only media you have permission to share.

GITHUB PAGES
------------
See README.md for GitHub Pages publishing steps. Upload the extracted project contents, not the
ZIP file. This is a static HTML/CSS/JavaScript site and has no build step or dependencies.

VIBRANT ARCADE UPDATE
---------------------
The optional arcade now has a colourful illustrated hero, Pixel companion artwork, four themed
game-cover scenes, bigger touch-friendly controls and a live completion tracker. Each of the
four mini-games has its own colour palette and a clear completed state.

ORIGINAL FILES
--------------
